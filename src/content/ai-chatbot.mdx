## 🛠️ Step 1 — Build Your Chatbot

Go to **[lovable.dev](https://lovable.dev)** (free to start), click **"New Project"** and paste this exact prompt:

```text
Build me a complete AI-powered chatbot web application
that I can sell to local businesses like restaurants,
salons, and clinics.

Requirements:
— Single page app, fully mobile responsive
— Floating chat widget (bottom right corner)
— Pulse animation on chat button to grab attention
— Business name, logo placeholder and green Online dot in header
— Typing indicator (3 dots) while AI is thinking
— Claude AI integrated as the brain (claude-sonnet model)
— API key input field on a settings page
— Quick Reply buttons after every message
— Smart greeting based on time (Good Morning / Evening etc)
— Lead capture: ask name + number after 2nd message
— Save all leads in a simple admin panel
— Admin panel protected by password: admin123
— Export leads as CSV from admin panel
— WhatsApp redirect button always visible
— If user types 'human' or 'agent' → show WhatsApp button
— Offline message shown outside business hours
— Full conversation memory in session
— Clean premium design like Intercom or Tidio
— Brand color customizable via one variable at top of code
— At bottom show: Powered by [Your Name/Agency]
— Business details (name, services, hours, location,
   offers, WhatsApp number) all editable in one config
   section at the top of the code

Make it look so premium that a business owner would
happily pay ₹5,000–₹10,000 for it.
Fully working. No placeholders. No dummy data.
```

Hit **Generate** → Wait 2 mins ✅  
Your chatbot is **READY** 🎉
